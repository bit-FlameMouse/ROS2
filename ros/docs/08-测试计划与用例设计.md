### 1.1 测试金字塔

```
                    ╱╲
                   ╱  ╲         系统验收测试（TC-S-*）      12 项
                  ╱────╲        — 仿真环境人工执行，决定演示成败
```

### 1.2 测试原则

| 原则 | 说明 |
| --- | --- |
| 纯逻辑优先测 | `WaypointLoader` / `PatrolStateMachine` / `SafetyEvaluator` 无 ROS 运行时依赖，优先覆盖 |
| 先验证依赖，再验证自研 | 用 `ros2 action send_goal` 确认 Nav2 正常，再测巡逻节点（避免误判） |
| 可复现 | 每个用例写清前置状态与判定标准，结果可重复 |
| 有据可查 | 系统测试必须留截图/日志/录屏，不靠"我试过是好的" |
| 时间盒 | 单元测试 ≤ 5 分钟跑完；单条系统用例 ≤ 10 分钟 |

### 1.3 测试范围与不测范围

| 范围 | 说明 |
| --- | --- |
| ✅ 测 | 自研三个纯逻辑类、两个节点、5 条 launch 链路的联通性、12 项系统验收 |
| ❌ 不测 | Nav2 内部算法正确性、Gazebo 物理引擎精度、SLAM 算法收敛性（属第三方责任） |
| ❌ 不做 | 负载/压力测试（单机器人场景不适用）、安全性渗透测试 |

### 3.1 TC-U-01 ~ TC-U-03：`WaypointLoader`

| 编号 | 用例名 | 输入 | 期望输出 |
| --- | --- | --- | --- |
| TC-U-01 | 正常解析 | `x=[1,2]`, `y=[3,4]`, `yaw=[0,1.57]`, `wait=[2,3]` | `true`；2 个航点；字段值正确；`index=0,1` |
| TC-U-02 | 长度不一致 | `x=[1,2]`, `y=[3]`, `yaw=[0,1]`, `wait=[2,3]` | `false`；error 含"长度不一致" |
| TC-U-03 | 空数组 | 全部为空 | `false`；error 含"未配置任何航点" |

**补充用例（边界）**：

| 编号 | 用例名 | 输入 | 期望 |
| --- | --- | --- | --- |
| TC-U-03a | 负停留时间 | `wait=[-1]` | `false`；error 含"不能为负" |
| TC-U-03b | NaN 值 | `x=[nan]` | `false`；error 含"非法数值" |
| TC-U-03c | yaw 归一化 | `yaw=[3π]` | 结果 `≈π` |
| TC-U-03d | yaw 归一化（负） | `yaw=[-3π]` | 结果 `≈π` 或 `≈-π`（幅度为 π） |
| TC-U-03e | 单航点 | 各数组长度 1 | `true`；1 个航点 |
| TC-U-03f | Inf 值 | `y=[inf]` | `false` |

**示例代码骨架**：

```cpp
#include <gtest/gtest.h>
#include <cmath>
#include "patrol_robot_core/waypoint_loader.hpp"

using namespace patrol_robot_core;

TEST(WaypointLoaderTest, ParseValidArrays)
{
  WaypointSet set;
  std::string error;
  const bool ok = WaypointLoader::fromArrays(
    {1.0, 2.0}, {3.0, 4.0}, {0.0, 1.57}, {2.0, 3.0}, "map", set, error);
  ASSERT_TRUE(ok) << error;
  ASSERT_EQ(set.waypoints.size(), 2u);
  EXPECT_DOUBLE_EQ(set.waypoints[0].x, 1.0);
  EXPECT_DOUBLE_EQ(set.waypoints[1].wait_sec, 3.0);
  EXPECT_EQ(set.waypoints[1].index, 1u);
  EXPECT_EQ(set.frame_id, "map");
}

TEST(WaypointLoaderTest, RejectMismatchedLengths)
{
  WaypointSet set;
  std::string error;
  const bool ok = WaypointLoader::fromArrays(
    {1.0, 2.0}, {3.0}, {0.0, 1.0}, {2.0, 3.0}, "map", set, error);
  EXPECT_FALSE(ok);
  EXPECT_NE(error.find("长度不一致"), std::string::npos);
}

TEST(WaypointLoaderTest, RejectEmptyArrays)
{
  WaypointSet set;
  std::string error;
  EXPECT_FALSE(WaypointLoader::fromArrays({}, {}, {}, {}, "map", set, error));
  EXPECT_FALSE(error.empty());
}
```

### 3.2 TC-U-04：`PatrolStateMachine` 完整迁移覆盖

| 编号 | 用例名 | 事件序列 | 期望 |
| --- | --- | --- | --- |
| TC-U-04a | 完成一轮（loop=1） | START → (SUCCEEDED → WAIT_ELAPSED) ×3 | 最终 IDLE；`completed=3`；`loop=1`；`finishedAllLoops=true` |
| TC-U-04b | 无限循环 | loop=0，完成一轮 | `index=0`；状态 MOVING；`finishedAllLoops=false` |
| TC-U-04c | 重试超限 | max_retries=2；START → GOAL_FAILED ×2 | 状态 FAILED；`errorCode=4` |
| TC-U-04d | 跳过失败点 | max_retries=2，skip=true，3 个航点；航点 0 连失败 2 次 | `index=1`；状态 MOVING；`retry=0` |
| TC-U-04e | 暂停/恢复 | START → PAUSE → RESUME | PAUSED 时 `cancel_goal=true`；RESUME 后 MOVING 且 `target_index` 不变 |
| TC-U-04f | 安全暂停/恢复 | START → SAFETY_TRIGGERED → SAFETY_CLEARED | SAFETY_HOLD → MOVING；两次命令正确 |
| TC-U-04g | STOP 归零 | START → STOP | IDLE；`index=0`；`cancel_goal=true` |
| TC-U-04h | 空航点 START | waypoint_count=0 + START | IDLE；`errorCode=1`；`send_goal=false` |
| TC-U-04i | 幂等 PAUSE | IDLE + PAUSE | 状态不变；无副作用 |
| TC-U-04j | 非法事件 | IDLE + GOAL_SUCCEEDED | 状态不变；无副作用 |
| TC-U-04k | RESET 清统计 | 完成一轮后 RESET | `completed=0`；`loop=0`；`errorCode=0` |
| TC-U-04l | FAILED 后 RESET | FAILED + RESET | 状态 IDLE；`index=0` |
| TC-U-04m | 等待期暂停/恢复 | START → SUCCEEDED → WAITING → PAUSE → RESUME | RESUME 回 WAITING；`restart_wait=true`；`send_goal=false`；`completed` 不重复计数 |
| TC-U-04n | 等待期安全暂停/恢复 | START → SUCCEEDED → WAITING → SAFETY_TRIGGERED → SAFETY_CLEARED | SAFETY_HOLD → WAITING；`restart_wait=true`；`send_goal=false` |

> **覆盖率目标**：状态迁移表（04 §5.2）中每一行至少被一个用例覆盖，覆盖率 100%。

### 3.3 TC-U-06：`SafetyEvaluator`

| 编号 | 用例名 | 构造输入 | 期望 |
| --- | --- | --- | --- |
| TC-U-06a | 无障碍 | 所有 range = 5.0（超 range_max） | `emergency=false`；`has_valid_point=false` |
| TC-U-06b | 正前方 0.2 m 障碍 | 中心点 range=0.2，其余 5.0 | `emergency=true`；`state_changed=true`；`min_distance≈0.2` |
| TC-U-06c | 迟滞区间内不翻转 | 先触发（0.2），再给 0.45（在 0.3~0.6 之间） | `emergency=true` 保持；`state_changed=false` |
| TC-U-06d | 超过 resume 解除 | 先触发，再给 0.8 | `emergency=false`；`state_changed=true` |
| TC-U-06e | 侧向障碍不触发 | 角度 90° 处 range=0.1，正前方 5.0 | `emergency=false`（fov=60° 不含 90°） |
| TC-U-06f | NaN 过滤 | 正前方 range=NaN，其余 5.0 | 不崩溃；`emergency=false` |
| TC-U-06g | 空数组 | `ranges=[]` | 不崩溃；状态保持 |
| TC-U-06h | 参数非法 | `stop=0.8, resume=0.6` | `validateConfig` 返回 false |
| TC-U-06i | 边界值 | 正前方恰好 0.30（= stop） | 不触发（严格小于才触发），`emergency=false` |

**示例代码骨架**：

```cpp
#include <gtest/gtest.h>
#include <limits>
#include <vector>
#include "patrol_robot_core/safety_evaluator.hpp"

using namespace patrol_robot_core;

namespace
{
sensor_msgs::msg::LaserScan makeScan(const std::vector<double> & ranges)
{
  sensor_msgs::msg::LaserScan scan;
  scan.angle_min = -3.14159f;
  scan.angle_max = 3.14159f;
  scan.angle_increment = static_cast<float>(2.0 * 3.14159 / ranges.size());
  scan.range_min = 0.12f;
  scan.range_max = 3.5f;
  for (double r : ranges) {
    scan.ranges.push_back(static_cast<float>(r));
  }
  return scan;
}

sensor_msgs::msg::LaserScan centeredObstacle(size_t n, double front, double other = 5.0)
{
  std::vector<double> ranges(n, other);
  ranges[n / 2] = front;   // 索引中点对应角度 ≈ 0
  return makeScan(ranges);
}
}  // namespace

TEST(SafetyEvaluatorTest, TriggersOnCloseObstacle)
{
  SafetyEvaluator::Config cfg;   // stop=0.30, resume=0.60
  SafetyEvaluator ev(cfg);
  const auto r = ev.update(centeredObstacle(361, 0.20));
  EXPECT_TRUE(r.emergency);
  EXPECT_TRUE(r.state_changed);
  EXPECT_NEAR(r.min_distance, 0.20, 0.02);
}

TEST(SafetyEvaluatorTest, HysteresisHoldsState)
{
  SafetyEvaluator ev(SafetyEvaluator::Config{});
  ev.update(centeredObstacle(361, 0.20));            // 触发
  const auto r = ev.update(centeredObstacle(361, 0.45));  // 迟滞区间
  EXPECT_TRUE(r.emergency);
  EXPECT_FALSE(r.state_changed);
}

TEST(SafetyEvaluatorTest, RejectsInvalidConfig)
{
  SafetyEvaluator::Config cfg;
  cfg.stop_distance = 0.8;
  cfg.resume_distance = 0.6;
  std::string error;
  EXPECT_FALSE(SafetyEvaluator::validateConfig(cfg, error));
  EXPECT_FALSE(error.empty());
}
```
