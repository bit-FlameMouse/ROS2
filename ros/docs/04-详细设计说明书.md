## 3. `WaypointLoader` 模块详细设计

### 3.1 职责

把 ROS 参数中的 4 个平行数组（`waypoint_x` / `waypoint_y` / `waypoint_yaw` / `waypoint_wait`）
解析为结构化航点列表，并做完整性校验。**不依赖 ROS 运行时**，可独立单元测试（NFR-11）。

### 3.2 为什么用平行数组而不是字符串

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 4 个平行 `double[]` | YAML 原生类型、无需手写解析、类型安全、支持参数动态修改 | 数组必须等长，靠校验保证 | **采纳** |
| `string[]` 如 `"1.0,2.0,0.5,2.0"` | 单个参数 | 需自行解析与错误处理，可读性差 | 否 |
| 独立 YAML 文件路径 | 航点可独立管理 | 需文件 IO + yaml-cpp 依赖，参数化程度低 | 否（列入 Roadmap） |

### 3.3 类设计

```
┌─────────────────────────────────┐
│ WaypointLoader                  │  (纯逻辑，无 ROS 运行时依赖)
├─────────────────────────────────┤
│ + fromArrays(xs, ys, yaws,      │
│     waits, frame_id, out,       │
│     error) : bool               │
│ + validate(set, error) : bool   │
│ + describe(set) : string        │
│ + normalizeAngle(yaw) : double  │
└─────────────────────────────────┘
        ▲
        │ 使用
┌───────┴─────────────────────────┐
│ patrol_node                     │  (负责 declare/get_parameter)
└─────────────────────────────────┘
```

### 3.4 校验规则

| 编号 | 规则 | 违反后果 |
| --- | --- | --- |
| VL-01 | 4 个数组长度必须相等 | 返回 false，ERROR 日志，START 服务返回失败（FR-06.3） |
| VL-02 | 航点数量 ≥ 1 | 同上 |
| VL-03 | `wait_sec ≥ 0` | 同上 |
| VL-04 | `yaw` 归一化到 `(-π, π]` | 自动归一化 |
| VL-05 | 所有值必须为有限数（非 NaN/Inf） | 返回 false |

### 3.5 完整代码

`include/patrol_robot_core/waypoint_loader.hpp`

```cpp
// 文件用途：航点数据结构定义与参数解析（纯逻辑，不依赖 ROS 运行时）
#ifndef PATROL_ROBOT_CORE__WAYPOINT_LOADER_HPP_
#define PATROL_ROBOT_CORE__WAYPOINT_LOADER_HPP_

#include <cstdint>
#include <string>
#include <vector>

namespace patrol_robot_core
{

/// @brief 单个航点：地图坐标系下的目标位姿与停留时间
struct Waypoint
{
  double x{0.0};         ///< 目标 x（m）
  double y{0.0};         ///< 目标 y（m）
  double yaw{0.0};       ///< 目标偏航角（rad），归一化到 (-pi, pi]
  double wait_sec{0.0};  ///< 到达后停留时间（s）
  uint32_t index{0};     ///< 序号，由加载器填充
};

/// @brief 一次巡逻任务的航点集合
struct WaypointSet
{
  std::vector<Waypoint> waypoints;
  std::string frame_id{"map"};
  std::string name{"default"};
};

/// @brief 航点加载器：纯函数式解析 + 校验
class WaypointLoader
{
public:
  /// @brief 由平行数组构造航点集合
  /// @param xs        x 坐标数组
  /// @param ys        y 坐标数组
  /// @param yaws      偏航角数组（rad）
  /// @param waits     停留时间数组（s）
  /// @param frame_id  参考坐标系
  /// @param[out] out   解析结果（失败时不保证有效）
  /// @param[out] error 失败原因（成功时被清空）
  /// @return 解析并校验成功返回 true
  static bool fromArrays(
    const std::vector<double> & xs,
    const std::vector<double> & ys,
    const std::vector<double> & yaws,
    const std::vector<double> & waits,
    const std::string & frame_id,
    WaypointSet & out,
    std::string & error);

  /// @brief 校验航点集合的合法性
  static bool validate(const WaypointSet & set, std::string & error);

  /// @brief 生成人类可读的描述（用于启动日志）
  static std::string describe(const WaypointSet & set);

  /// @brief 把角度归一化到 (-pi, pi]
  static double normalizeAngle(double yaw);
};

}  // namespace patrol_robot_core

#endif  // PATROL_ROBOT_CORE__WAYPOINT_LOADER_HPP_
```

`src/waypoint_loader.cpp`

```cpp
// 文件用途：WaypointLoader 实现
#include "patrol_robot_core/waypoint_loader.hpp"

#include <cmath>
#include <sstream>

namespace patrol_robot_core
{
namespace
{
constexpr double kPi = 3.14159265358979323846;
}  // namespace

double WaypointLoader::normalizeAngle(double yaw)
{
  double a = std::fmod(yaw + kPi, 2.0 * kPi);
  if (a < 0.0) {
    a += 2.0 * kPi;
  }
  return a - kPi;
}

bool WaypointLoader::fromArrays(
  const std::vector<double> & xs,
  const std::vector<double> & ys,
  const std::vector<double> & yaws,
  const std::vector<double> & waits,
  const std::string & frame_id,
  WaypointSet & out,
  std::string & error)
{
  error.clear();
  out.waypoints.clear();
  out.frame_id = frame_id;

  // VL-01：长度一致性
  if (xs.size() != ys.size() || xs.size() != yaws.size() || xs.size() != waits.size()) {
    std::ostringstream oss;
    oss << "航点参数数组长度不一致: x=" << xs.size() << ", y=" << ys.size()
        << ", yaw=" << yaws.size() << ", wait=" << waits.size();
    error = oss.str();
    return false;
  }

  // VL-02：至少一个航点
  if (xs.empty()) {
    error = "未配置任何航点（waypoint_x 为空）";
    return false;
  }

  for (size_t i = 0; i < xs.size(); ++i) {
    // VL-05：有限性
    if (!std::isfinite(xs[i]) || !std::isfinite(ys[i]) ||
      !std::isfinite(yaws[i]) || !std::isfinite(waits[i]))
    {
      std::ostringstream oss;
      oss << "航点 " << i << " 包含非法数值（NaN/Inf）";
      error = oss.str();
      return false;
    }
    // VL-03：停留时间非负
    if (waits[i] < 0.0) {
      std::ostringstream oss;
      oss << "航点 " << i << " 的停留时间不能为负: " << waits[i];
      error = oss.str();
      return false;
    }

    Waypoint wp;
    wp.x = xs[i];
    wp.y = ys[i];
    wp.yaw = normalizeAngle(yaws[i]);  // VL-04
    wp.wait_sec = waits[i];
    wp.index = static_cast<uint32_t>(i);
    out.waypoints.push_back(wp);
  }

  return validate(out, error);
}

bool WaypointLoader::validate(const WaypointSet & set, std::string & error)
{
  error.clear();
  if (set.waypoints.empty()) {
    error = "航点集合为空";
    return false;
  }
  if (set.frame_id.empty()) {
    error = "frame_id 不能为空";
    return false;
  }
  for (const auto & wp : set.waypoints) {
    if (!std::isfinite(wp.x) || !std::isfinite(wp.y) ||
      !std::isfinite(wp.yaw) || !std::isfinite(wp.wait_sec))
    {
      error = "航点包含非法数值";
      return false;
    }
    if (wp.wait_sec < 0.0) {
      error = "航点停留时间为负";
      return false;
    }
  }
  return true;
}

std::string WaypointLoader::describe(const WaypointSet & set)
{
  std::ostringstream oss;
  oss << "航点集合 frame=" << set.frame_id << " count=" << set.waypoints.size();
  for (const auto & wp : set.waypoints) {
    oss << "\n  [" << wp.index << "] x=" << wp.x << " y=" << wp.y
        << " yaw=" << wp.yaw << " wait=" << wp.wait_sec << "s";
  }
  return oss.str();
}

}  // namespace patrol_robot_core
```

### 3.6 边界与异常场景

| 场景 | 行为 |
| --- | --- |
| 参数未声明 | `patrol_node` 声明时给默认值 `[]`，`fromArrays` 返回 false，节点以 WARN 启动但不崩溃，START 服务返回 `NO_WAYPOINTS` |
| 航点重复 | 允许。Nav2 会立即返回成功，停留后进入下一个 |
| 航点落在障碍物内 | 允许配置，运行时会重试并最终跳过（FR-11） |
| yaw 传 3π | 自动归一化为 π |

## 4. `NavClient` 模块详细设计

### 4.1 职责

封装 `nav2_msgs/action/NavigateToPose`，对上层提供**非阻塞**的
「发送目标 / 取消目标 / 查询任务状态」接口。

### 4.2 为什么必须非阻塞（ADR-05 的落地细节）

**错误示范（会死锁）**：

```cpp
// ✗ 危险：在单线程执行器的回调里阻塞等待 Action 结果
auto goal_future = client_->async_send_goal(goal);
auto goal_handle = goal_future.get();   // ← 永久阻塞，且无任何报错
```

死锁成因：`goal_future` 的完成依赖 `goal_response_callback` 被调用，
而回调必须由执行器线程调用——该线程正被 `.get()` 阻塞。

**正确做法**：`async_send_goal` 立即返回，状态由回调更新，上层通过 `state()` 轮询判断。

### 4.3 状态机

```
        sendGoal()              onGoalResponse(handle != nullptr)
 IDLE ─────────────► PENDING ──────────────────────────────► ACTIVE
   ▲                     │                                      │
   │                     │ onGoalResponse(nullptr)              │ onResult()
   │                     ▼                                      ▼
   │                  REJECTED            SUCCEEDED / ABORTED / CANCELED
   │                                                              │
   └──────────────── detach() / 下一次 sendGoal() ◄────────────────┘
```

### 4.4 回调时序

```
patrol_node          NavClient                 Nav2 Action Server
    │                    │                              │
    │ sendGoal(x,y,yaw)  │                              │
    │───────────────────►│ wait_for_action_server(5s)   │
    │                    │─────────────────────────────►│
    │                    │ async_send_goal() ──────────►│
    │  (立即返回 true)    │                              │
    │◄───────────────────│                              │
    │                    │◄── goal_response_callback ───│  PENDING → ACTIVE
    │                    │◄── feedback_callback ────────│  更新 remaining/recoveries
    │                    │◄── result_callback ──────────│  → SUCCEEDED/ABORTED
    │ tick(): 读取 state  │                              │
```

### 4.5 完整代码

`include/patrol_robot_core/nav_client.hpp`

```cpp
// 文件用途：Nav2 NavigateToPose Action 的非阻塞客户端封装
#ifndef PATROL_ROBOT_CORE__NAV_CLIENT_HPP_
#define PATROL_ROBOT_CORE__NAV_CLIENT_HPP_

#include <chrono>
#include <cstdint>
#include <memory>
#include <mutex>
#include <string>

#include "nav2_msgs/action/navigate_to_pose.hpp"
#include "rclcpp/rclcpp.hpp"
#include "rclcpp_action/rclcpp_action.hpp"

namespace patrol_robot_core
{

/// @brief 单次导航任务的状态
enum class NavTaskState : uint8_t
{
  IDLE = 0,    ///< 未发送目标
  PENDING,     ///< 已发送，等待服务器接受
  ACTIVE,      ///< 已接受，导航进行中
  SUCCEEDED,   ///< 到达目标
  ABORTED,     ///< 导航失败
  CANCELED,    ///< 被取消
  REJECTED,    ///< 目标被服务器拒绝
};

const char * toString(NavTaskState state);

/// @brief NavigateToPose Action 客户端封装（非阻塞）
class NavClient
{
public:
  using NavigateToPose = nav2_msgs::action::NavigateToPose;
  using GoalHandle = rclcpp_action::ClientGoalHandle<NavigateToPose>;

  /// @param node        宿主节点（不持有所有权）
  /// @param action_name Action 名称，默认 "navigate_to_pose"
  /// @param frame_id    目标位姿参考坐标系，通常为 "map"
  NavClient(rclcpp::Node * node, const std::string & action_name, const std::string & frame_id);

  /// @brief 阻塞等待 Action Server 就绪
  bool waitForServer(std::chrono::milliseconds timeout);

  /// @brief 发送导航目标（非阻塞，立即返回）
  /// @return 是否成功提交（不代表导航成功）
  bool sendGoal(double x, double y, double yaw);

  /// @brief 请求取消当前目标
  void cancel();

  /// @brief 清空内部状态（下一次 sendGoal 前调用，避免读到旧结果）
  void detach();

  /// @brief 当前任务状态（线程安全）
  NavTaskState state() const;

  /// @brief 是否处于终态
  bool isFinished() const;

  /// @brief 距目标剩余距离（m），无反馈时返回 -1.0
  double distanceRemaining() const;

  /// @brief Nav2 触发恢复行为的次数
  int16_t recoveryCount() const;

private:
  void onGoalResponse(GoalHandle::SharedPtr goal_handle);
  void onFeedback(
    GoalHandle::SharedPtr,
    const std::shared_ptr<const NavigateToPose::Feedback> feedback);
  void onResult(const GoalHandle::WrappedResult & result);

  rclcpp::Node * node_{nullptr};
  std::string frame_id_;
  rclcpp_action::Client<NavigateToPose>::SharedPtr client_;

  mutable std::mutex mutex_;
  NavTaskState state_{NavTaskState::IDLE};
  GoalHandle::SharedPtr goal_handle_;
  double distance_remaining_{-1.0};
  int16_t recovery_count_{0};
  bool goal_sent_{false};
};

}  // namespace patrol_robot_core

#endif  // PATROL_ROBOT_CORE__NAV_CLIENT_HPP_
```

`src/nav_client.cpp`

```cpp
// 文件用途：NavClient 实现
#include "patrol_robot_core/nav_client.hpp"

#include <functional>
#include <utility>

#include "tf2/LinearMath/Quaternion.h"
#include "tf2_geometry_msgs/tf2_geometry_msgs.hpp"

namespace patrol_robot_core
{
using namespace std::chrono_literals;

const char * toString(NavTaskState state)
{
  switch (state) {
    case NavTaskState::IDLE: return "IDLE";
    case NavTaskState::PENDING: return "PENDING";
    case NavTaskState::ACTIVE: return "ACTIVE";
    case NavTaskState::SUCCEEDED: return "SUCCEEDED";
    case NavTaskState::ABORTED: return "ABORTED";
    case NavTaskState::CANCELED: return "CANCELED";
    case NavTaskState::REJECTED: return "REJECTED";
  }
  return "UNKNOWN";
}

NavClient::NavClient(
  rclcpp::Node * node, const std::string & action_name, const std::string & frame_id)
: node_(node), frame_id_(frame_id)
{
  client_ = rclcpp_action::create_client<NavigateToPose>(node_, action_name);
}

bool NavClient::waitForServer(std::chrono::milliseconds timeout)
{
  if (!client_) {
    return false;
  }
  return client_->wait_for_action_server(timeout);
}

bool NavClient::sendGoal(double x, double y, double yaw)
{
  if (!waitForServer(5s)) {
    RCLCPP_ERROR(node_->get_logger(), "[NavClient] Action server 不可用，目标未发送");
    return false;
  }

  NavigateToPose::Goal goal;
  goal.pose.header.frame_id = frame_id_;
  goal.pose.header.stamp = node_->now();
  goal.pose.pose.position.x = x;
  goal.pose.pose.position.y = y;
  goal.pose.pose.position.z = 0.0;

  tf2::Quaternion q;
  q.setRPY(0.0, 0.0, yaw);
  goal.pose.pose.orientation = tf2::toMsg(q);

  {
    std::lock_guard<std::mutex> lock(mutex_);
    state_ = NavTaskState::PENDING;
    distance_remaining_ = -1.0;
    recovery_count_ = 0;
    goal_sent_ = true;
  }

  auto options = rclcpp_action::Client<NavigateToPose>::SendGoalOptions();
  options.goal_response_callback =
    std::bind(&NavClient::onGoalResponse, this, std::placeholders::_1);
  options.feedback_callback =
    std::bind(&NavClient::onFeedback, this, std::placeholders::_1, std::placeholders::_2);
  options.result_callback =
    std::bind(&NavClient::onResult, this, std::placeholders::_1);

  client_->async_send_goal(goal, options);

  RCLCPP_INFO(
    node_->get_logger(), "[NavClient] 目标已发送: x=%.2f y=%.2f yaw=%.2f frame=%s",
    x, y, yaw, frame_id_.c_str());
  return true;
}

void NavClient::cancel()
{
  GoalHandle::SharedPtr handle;
  bool cancel_all = false;
  {
    std::lock_guard<std::mutex> lock(mutex_);
    handle = goal_handle_;
    cancel_all = (handle == nullptr) && goal_sent_;
  }

  if (handle) {
    client_->async_cancel_goal(handle);
    RCLCPP_WARN(node_->get_logger(), "[NavClient] 已请求取消当前导航目标");
  } else if (cancel_all) {
    // 目标刚发出、服务器尚未响应
    client_->async_cancel_all_goals();
    RCLCPP_WARN(node_->get_logger(), "[NavClient] 目标尚未被接受，已请求取消全部目标");
  }
}

void NavClient::detach()
{
  std::lock_guard<std::mutex> lock(mutex_);
  state_ = NavTaskState::IDLE;
  goal_handle_.reset();
  distance_remaining_ = -1.0;
  recovery_count_ = 0;
  goal_sent_ = false;
}

NavTaskState NavClient::state() const
{
  std::lock_guard<std::mutex> lock(mutex_);
  return state_;
}

bool NavClient::isFinished() const
{
  std::lock_guard<std::mutex> lock(mutex_);
  return state_ == NavTaskState::SUCCEEDED || state_ == NavTaskState::ABORTED ||
         state_ == NavTaskState::CANCELED || state_ == NavTaskState::REJECTED;
}

double NavClient::distanceRemaining() const
{
  std::lock_guard<std::mutex> lock(mutex_);
  return distance_remaining_;
}

int16_t NavClient::recoveryCount() const
{
  std::lock_guard<std::mutex> lock(mutex_);
  return recovery_count_;
}

void NavClient::onGoalResponse(GoalHandle::SharedPtr goal_handle)
{
  std::lock_guard<std::mutex> lock(mutex_);
  if (!goal_handle) {
    state_ = NavTaskState::REJECTED;
    return;
  }
  goal_handle_ = goal_handle;
  state_ = NavTaskState::ACTIVE;
}

void NavClient::onFeedback(
  GoalHandle::SharedPtr,
  const std::shared_ptr<const NavigateToPose::Feedback> feedback)
{
  std::lock_guard<std::mutex> lock(mutex_);
  distance_remaining_ = static_cast<double>(feedback->distance_remaining);
  recovery_count_ = feedback->number_of_recoveries;
}

void NavClient::onResult(const GoalHandle::WrappedResult & result)
{
  std::lock_guard<std::mutex> lock(mutex_);
  goal_handle_.reset();
  switch (result.code) {
    case rclcpp_action::ResultCode::SUCCEEDED:
      state_ = NavTaskState::SUCCEEDED;
      distance_remaining_ = 0.0;
      break;
    case rclcpp_action::ResultCode::ABORTED:
      state_ = NavTaskState::ABORTED;
      break;
    case rclcpp_action::ResultCode::CANCELED:
      state_ = NavTaskState::CANCELED;
      break;
    default:
      state_ = NavTaskState::ABORTED;
      break;
  }
}
```

| 成员 | 保护方式 |
| --- | --- |
| `state_` / `goal_handle_` / `distance_remaining_` / `recovery_count_` / `goal_sent_` | `mutex_` 保护，回调与查询处均加锁 |

## 5. `PatrolStateMachine` 设计

### 5.1 状态定义

| 状态 | 值 | 含义 | 允许的外部事件 |
| --- | --- | --- | --- |
| `IDLE` | 0 | 空闲，未巡逻 | START、RESET |
| `MOVING` | 1 | 正在前往目标航点 | GOAL_SUCCEEDED、GOAL_FAILED、PAUSE、STOP、SAFETY_TRIGGERED |
| `WAITING` | 2 | 到达航点，停留计时中 | WAIT_ELAPSED、PAUSE、STOP、SAFETY_TRIGGERED |
| `PAUSED` | 3 | 人工暂停 | RESUME、STOP、RESET |
| `SAFETY_HOLD` | 4 | 安全守护导致暂停 | SAFETY_CLEARED、STOP |
| `FAILED` | 5 | 任务失败终止 | STOP、RESET |

> 状态值与 `PatrolStatus.msg` 中的 `MODE_*` 常量一一对应，可直接类型转换。

### 5.2 状态迁移表

| 当前状态 | 事件 | 下一状态 | 副作用（SmCommand） |
| --- | --- | --- | --- |
| IDLE | START | MOVING | `send_goal(idx=current)` |
| IDLE | START（航点数为 0） | IDLE | 无；错误码 1 `ERR_NO_WAYPOINTS` |
| IDLE | 其他 | IDLE | 无 |
| MOVING | GOAL_SUCCEEDED | WAITING | `completed++`；`retry=0`；`wait_start=now` |
| MOVING | GOAL_FAILED（`retry < max_retries`） | MOVING | `retry++`；`send_goal(idx)` |
| MOVING | GOAL_FAILED（超限，有下一点且 `skip=true`） | MOVING | `advance()`；`send_goal(new_idx)` |
| MOVING | GOAL_FAILED（超限，无下一点或 `skip=false`） | FAILED | 错误码 4 `ERR_MAX_RETRIES_EXCEEDED` |
| MOVING | PAUSE | PAUSED | `cancel_goal` |
| MOVING | SAFETY_TRIGGERED | SAFETY_HOLD | `cancel_goal` |
| MOVING | STOP | IDLE | `cancel_goal`；索引归零 |
| WAITING | WAIT_ELAPSED（有下一点） | MOVING | `advance()`；`send_goal(new_idx)` |
| WAITING | WAIT_ELAPSED（本轮结束且未达循环上限） | MOVING | `loop++`；`idx=0`；`send_goal(0)` |
| WAITING | WAIT_ELAPSED（本轮结束且已达上限） | IDLE | 标记 `finished_all_`，日志"巡逻完成" |
| WAITING | PAUSE | PAUSED | `cancel_goal`（幂等） |
| WAITING | SAFETY_TRIGGERED | SAFETY_HOLD | `cancel_goal` |
| PAUSED | RESUME | MOVING | `send_goal(current_idx)`（幂等） |
| PAUSED | STOP | IDLE | 索引归零 |
| SAFETY_HOLD | SAFETY_CLEARED | MOVING | `send_goal(current_idx)` |
| SAFETY_HOLD | STOP | IDLE | 索引归零 |
| FAILED | RESET / STOP | IDLE | 清零统计与错误 |
| 任意 | RESET | 不变 | 清零 `completed/retry/loop/error`；若为 FAILED 则回 IDLE |

> **简化决策**：`RESUME` 一律重新发送当前航点目标，而不是"接着停表"。
> 理由是机器人可能已被挪动，重新导航更安全；且 Nav2 对"已在目标点"的目标会立即返回成功，
> 代价可忽略。

```cpp
    case PatrolEvent::GOAL_FAILED: return "GOAL_FAILED";

    case PatrolEvent::PAUSE: return "PAUSE";
    case PatrolEvent::RESUME: return "RESUME";

    case PatrolEvent::RESET: return "RESET";

  }

PatrolStateMachine::PatrolStateMachine(const Config & config)
: config_(config)
{
}

bool PatrolStateMachine::advanceIndex()
{
  if (index_ + 1 < config_.waypoint_count) {
    ++index_;
    return true;
  }
  return false;  // 本轮结束
}

double PatrolStateMachine::currentWaitSec() const
{
  if (index_ < config_.wait_table.size()) {
    return config_.wait_table[index_];
  }
  return 0.0;
}

SmCommand PatrolStateMachine::handle(PatrolEvent event)
{
  SmCommand cmd;

  switch (event) {
    case PatrolEvent::START:
      if (state_ == PatrolState::IDLE) {
        if (config_.waypoint_count == 0) {
          error_code_ = 1;  // ERR_NO_WAYPOINTS
          error_message_ = "未配置航点，无法开始巡逻";
          return cmd;
        }
        state_ = PatrolState::MOVING;
        cmd.send_goal = true;
        cmd.target_index = index_;
      }
      return cmd;

    case PatrolEvent::STOP:
      if (state_ != PatrolState::IDLE) {
        cmd.cancel_goal = true;
      }
      state_ = PatrolState::IDLE;
      index_ = 0;
      retry_ = 0;
      return cmd;

    case PatrolEvent::RESET:
      completed_ = 0;
      retry_ = 0;
      loop_ = 0;
      error_code_ = 0;
      error_message_.clear();
      finished_all_ = false;
      if (state_ == PatrolState::FAILED) {
        state_ = PatrolState::IDLE;
        index_ = 0;
      }
      return cmd;

    case PatrolEvent::PAUSE:
      if (state_ == PatrolState::MOVING || state_ == PatrolState::WAITING) {
        state_ = PatrolState::PAUSED;
        cmd.cancel_goal = true;
      }
      return cmd;

    case PatrolEvent::RESUME:
      if (state_ == PatrolState::PAUSED) {
        state_ = PatrolState::MOVING;
        cmd.send_goal = true;
        cmd.target_index = index_;
      }
      return cmd;

    case PatrolEvent::SAFETY_TRIGGERED:
      if (state_ == PatrolState::MOVING || state_ == PatrolState::WAITING) {
        state_ = PatrolState::SAFETY_HOLD;
        cmd.cancel_goal = true;
      }
      return cmd;

    case PatrolEvent::SAFETY_CLEARED:
      if (state_ == PatrolState::SAFETY_HOLD) {
        state_ = PatrolState::MOVING;
        cmd.send_goal = true;
        cmd.target_index = index_;
      }
      return cmd;

    case PatrolEvent::GOAL_SUCCEEDED:
      if (state_ == PatrolState::MOVING) {
        state_ = PatrolState::WAITING;
        ++completed_;
        retry_ = 0;
      }
      return cmd;

    case PatrolEvent::GOAL_FAILED:
      if (state_ != PatrolState::MOVING) {
        return cmd;
      }
      ++retry_;
      if (retry_ < static_cast<int32_t>(config_.max_retries)) {
        cmd.send_goal = true;
        cmd.target_index = index_;
        return cmd;
      }
      if (config_.skip_failed_waypoint && advanceIndex()) {
        retry_ = 0;
        cmd.send_goal = true;
        cmd.target_index = index_;
        return cmd;
      }
      state_ = PatrolState::FAILED;
      error_code_ = 4;  // ERR_MAX_RETRIES_EXCEEDED
      error_message_ = "航点重试次数超限，任务终止";
      return cmd;

    case PatrolEvent::WAIT_ELAPSED:
      if (state_ != PatrolState::WAITING) {
        return cmd;
      }
      if (advanceIndex()) {
        state_ = PatrolState::MOVING;
        cmd.send_goal = true;
        cmd.target_index = index_;
        return cmd;
      }
      // 本轮结束，判断是否继续循环
      ++loop_;
      if (config_.loop_count == 0 || loop_ < config_.loop_count) {
        index_ = 0;
        state_ = PatrolState::MOVING;
        cmd.send_goal = true;
        cmd.target_index = index_;
        return cmd;
      }
      finished_all_ = true;
      state_ = PatrolState::IDLE;
      index_ = 0;
      return cmd;
  }

  return cmd;
}

}  // namespace patrol_robot_core
```

| 用例 | 输入序列 | 期望 |
| --- | --- | --- |
| 正常一轮 | START → GOAL_SUCCEEDED → WAIT_ELAPSED ×3（loop_count=1） | 完成 3 个航点，loop=1，回 IDLE，`finished_all_=true` |
| 无限循环 | loop_count=0，走完一轮 | idx=0，状态 MOVING |

| 安全暂停 | START → SAFETY_TRIGGERED → SAFETY_CLEARED | SAFETY_HOLD → MOVING，先 cancel 后 send_goal |
| 空航点 | waypoint_count=0 + START | 状态 IDLE，错误码 1，无 send_goal |
| STOP 归零 | START → STOP | IDLE，idx=0，cancel_goal=true |
| 幂等 PAUSE | IDLE + PAUSE | 状态不变，无副作用 |

### 6.2 并发模型（关键设计）

**单点状态更新原则**：所有对 `PatrolStateMachine` 的调用**只发生在 `tick()` 中**。
外部事件（服务调用、安全标志）只做两件事：

1. 服务 `onSetMode()` 直接调用状态机（因为服务本身已经是"用户显式指令"，且不涉及导航结果竞态）；
2. 安全标志 `onSafetyEmergency()` **只更新 `emergency_` 布尔量**，真正的迁移交给下一次 tick。

这样设计的原因：Action 的结果回调在**另一个线程**执行，如果允许回调里直接驱动状态机，
会与 tick 线程并发修改状态。用"标志 + 单点迁移"模型，可以完全避免给状态机加锁。

### 6.3 `tick()` 逻辑

```
tick():
    state = sm.state()
    if state in {IDLE, PAUSED, FAILED}: return          # 不主动做事

    if state == SAFETY_HOLD:
        if not emergency_: applyCommand(sm.handle(SAFETY_CLEARED))
        return

    if emergency_ and use_safety_hold_:                  # 安全优先级最高
        applyCommand(sm.handle(SAFETY_TRIGGERED))
        return

    if state == MOVING:
        if waypoint_timeout_sec > 0 and (now - goal_start_) > waypoint_timeout_sec:
            nav.cancel(); applyCommand(sm.handle(GOAL_FAILED)); return
        match nav.state():
            SUCCEEDED  → applyCommand(sm.handle(GOAL_SUCCEEDED)); wait_start_ = now
            ABORTED    → applyCommand(sm.handle(GOAL_FAILED))
            REJECTED   → applyCommand(sm.handle(GOAL_FAILED))
            CANCELED   → if not cancel_expected_: applyCommand(sm.handle(GOAL_FAILED))
            other      → 忽略
        return

    if state == WAITING:
        if (now - wait_start_) >= sm.currentWaitSec():
            applyCommand(sm.handle(WAIT_ELAPSED))
            if sm.finishedAllLoops(): INFO "巡逻任务全部完成"
```

### 6.4 `applyCommand()` 逻辑

```
applyCommand(cmd):
    if cmd.cancel_goal:
        cancel_expected_ = true
        nav.cancel()

    if cmd.send_goal:
        if cmd.target_index >= waypoints.size(): ERROR 越界并返回
        nav.detach()                     # 清掉上一轮结果，避免误判
        ok = nav.sendGoal(wp.x, wp.y, wp.yaw)
        goal_start_ = now()
        cancel_expected_ = false
        if not ok:
            error_code_ = ERR_NAV_SERVER_UNAVAILABLE
            applyCommand(sm.handle(GOAL_FAILED))   # 递归，受 max_retries 上限保护
            return
        INFO "前往航点 [i] x=.. y=.. yaw=.. (wait=..s)"

    publishMarkers()
```

> **递归保护**：`applyCommand` 的递归只会在"发送失败"时发生，
> 每次递归都会消耗一次 `retry_`，最多 `max_retries` 层，不会栈溢出。

```cpp
#include <vector>

#include "geometry_msgs/msg/pose_stamped.hpp"
#include "patrol_interfaces/msg/patrol_status.hpp"
#include "patrol_interfaces/srv/set_patrol_mode.hpp"
#include "patrol_robot_core/nav_client.hpp"
#include "patrol_robot_core/patrol_state_machine.hpp"
#include "patrol_robot_core/waypoint_loader.hpp"
#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/bool.hpp"
#include "visualization_msgs/msg/marker.hpp"
#include "visualization_msgs/msg/marker_array.hpp"

namespace patrol_robot_core
{
using namespace std::chrono_literals;

class PatrolNode : public rclcpp::Node
{
public:
  PatrolNode()
  : rclcpp::Node("patrol_node")
  {
    declareParameters();
    loadWaypoints();
    buildStateMachine();
    createInterfaces();

    RCLCPP_INFO(get_logger(), "patrol_node 已启动，tick=%d ms", tick_period_ms_);
    if (waypoints_valid_) {
      RCLCPP_INFO(get_logger(), "%s", WaypointLoader::describe(waypoints_).c_str());
    }

    if (auto_start_) {
      RCLCPP_INFO(get_logger(), "auto_start=true，自动开始巡逻");
      applyCommand(sm_->handle(PatrolEvent::START));
    }
  }

private:
  // ---------------- 参数声明 ----------------
  void declareParameters()
  {
    waypoint_x_ = declare_parameter<std::vector<double>>("waypoint_x", {});
    waypoint_y_ = declare_parameter<std::vector<double>>("waypoint_y", {});
    waypoint_yaw_ = declare_parameter<std::vector<double>>("waypoint_yaw", {});
    waypoint_wait_ = declare_parameter<std::vector<double>>("waypoint_wait", {});

    loop_count_ = declare_parameter<int>("loop_count", 0);
    max_retries_ = declare_parameter<int>("max_retries", 2);
    skip_failed_waypoint_ = declare_parameter<bool>("skip_failed_waypoint", true);
    waypoint_timeout_sec_ = declare_parameter<double>("waypoint_timeout_sec", 60.0);
    auto_start_ = declare_parameter<bool>("auto_start", false);

    global_frame_ = declare_parameter<std::string>("global_frame", "map");
    action_name_ = declare_parameter<std::string>("action_name", "navigate_to_pose");
    status_topic_ = declare_parameter<std::string>("status_topic", "/patrol/status");
    markers_topic_ = declare_parameter<std::string>("markers_topic", "/patrol/markers");
    mode_service_ = declare_parameter<std::string>("mode_service", "/patrol/set_mode");
    safety_topic_ = declare_parameter<std::string>("safety_topic", "/safety/emergency_stop");

    tick_period_ms_ = declare_parameter<int>("tick_period_ms", 100);
    status_publish_hz_ = declare_parameter<double>("status_publish_hz", 1.0);
    use_safety_hold_ = declare_parameter<bool>("use_safety_hold", true);
  }

  // ---------------- 航点加载 ----------------
  void loadWaypoints()
  {
    std::string error;
    waypoints_valid_ = WaypointLoader::fromArrays(
      waypoint_x_, waypoint_y_, waypoint_yaw_, waypoint_wait_,
      global_frame_, waypoints_, error);
    if (!waypoints_valid_) {
      RCLCPP_ERROR(get_logger(), "航点参数校验失败：%s", error.c_str());
      RCLCPP_WARN(get_logger(), "节点以无航点模式运行，START 服务将返回失败");
    }
  }

  void buildStateMachine()
  {
    PatrolStateMachine::Config cfg;
    cfg.waypoint_count = static_cast<uint32_t>(waypoints_.waypoints.size());
    cfg.loop_count = static_cast<uint32_t>(loop_count_ < 0 ? 0 : loop_count_);
    cfg.max_retries = static_cast<uint32_t>(max_retries_ < 1 ? 1 : max_retries_);
    cfg.skip_failed_waypoint = skip_failed_waypoint_;
    cfg.wait_table = waypoint_wait_;
    sm_ = std::make_unique<PatrolStateMachine>(cfg);

    nav_ = std::make_unique<NavClient>(this, action_name_, global_frame_);
    if (!nav_->waitForServer(10s)) {
      RCLCPP_ERROR(
        get_logger(), "等待 Nav2 Action Server '%s' 超时，请确认 Nav2 已启动",
        action_name_.c_str());
    } else {
      RCLCPP_INFO(get_logger(), "Nav2 Action Server '%s' 已就绪", action_name_.c_str());
    }
  }

  // ---------------- 接口创建 ----------------
  void createInterfaces()
  {
    rclcpp::QoS marker_qos(1);
    marker_qos.transient_local();  // 晚启动的 RViz 也能收到航点

    marker_pub_ = create_publisher<visualization_msgs::msg::MarkerArray>(
      markers_topic_, marker_qos);
    status_pub_ = create_publisher<patrol_interfaces::msg::PatrolStatus>(status_topic_, 10);

    safety_sub_ = create_subscription<std_msgs::msg::Bool>(
      safety_topic_, rclcpp::QoS(1).transient_local(),
      std::bind(&PatrolNode::onSafetyEmergency, this, std::placeholders::_1));

    mode_srv_ = create_service<patrol_interfaces::srv::SetPatrolMode>(
      mode_service_,
      std::bind(
        &PatrolNode::onSetMode, this,
        std::placeholders::_1, std::placeholders::_2));

    tick_timer_ = create_wall_timer(
      std::chrono::milliseconds(tick_period_ms_),
      std::bind(&PatrolNode::tick, this));

    const double period_sec = 1.0 / std::max(0.1, status_publish_hz_);
    status_timer_ = create_wall_timer(
      std::chrono::milliseconds(static_cast<int>(period_sec * 1000.0)),
      std::bind(&PatrolNode::publishStatus, this));

    publishMarkers();
  }

  // ---------------- 安全守护回调（只置标志）----------------
  void onSafetyEmergency(const std_msgs::msg::Bool::SharedPtr msg)
  {
    if (!use_safety_hold_ || msg->data == emergency_) {
      return;
    }
    emergency_ = msg->data;
    RCLCPP_WARN(get_logger(), "安全标志变化: emergency=%s", emergency_ ? "true" : "false");
  }

  // ---------------- 模式控制服务 ----------------
  void onSetMode(
    const std::shared_ptr<patrol_interfaces::srv::SetPatrolMode::Request> request,
    std::shared_ptr<patrol_interfaces::srv::SetPatrolMode::Response> response)
  {
    using Req = patrol_interfaces::srv::SetPatrolMode::Request;

    PatrolEvent event{};
    bool valid = true;

    switch (request->mode) {
      case Req::REQ_START: event = PatrolEvent::START; break;
      case Req::REQ_PAUSE: event = PatrolEvent::PAUSE; break;
      case Req::REQ_RESUME: event = PatrolEvent::RESUME; break;
      case Req::REQ_STOP: event = PatrolEvent::STOP; break;
      case Req::REQ_RESET: event = PatrolEvent::RESET; break;
      default: valid = false; break;
    }

    if (!valid) {
      response->success = false;
      response->message = "未知的模式取值: " + std::to_string(request->mode);
      response->current_mode = toModeConstant(sm_->state());
      return;
    }

    if (event == PatrolEvent::START && !waypoints_valid_) {
      response->success = false;
      response->message = "NO_WAYPOINTS";
      response->current_mode = toModeConstant(sm_->state());
      RCLCPP_ERROR(get_logger(), "收到 START 请求但航点无效，已拒绝");
      return;
    }

    const auto before = sm_->state();
    applyCommand(sm_->handle(event));
    const bool changed = (sm_->state() != before);

    response->success = changed || (event == PatrolEvent::RESET);
    response->message = response->success ? "OK" : "NO_STATE_CHANGE";
    response->current_mode = toModeConstant(sm_->state());

    RCLCPP_INFO(
      get_logger(), "服务 %s → %s (%s)", toString(event), toString(sm_->state()),
      response->message.c_str());
  }

  // ---------------- 主 tick ----------------
  void tick()
  {
    const auto state = sm_->state();

    if (state == PatrolState::IDLE || state == PatrolState::PAUSED ||
      state == PatrolState::FAILED)
    {
      return;
    }

    if (state == PatrolState::SAFETY_HOLD) {
      if (!emergency_) {
        applyCommand(sm_->handle(PatrolEvent::SAFETY_CLEARED));
      }
      return;
    }

    if (emergency_ && use_safety_hold_) {
      applyCommand(sm_->handle(PatrolEvent::SAFETY_TRIGGERED));
      return;
    }

    if (state == PatrolState::MOVING) {
      const double elapsed = (now() - goal_start_).seconds();
      if (waypoint_timeout_sec_ > 0.0 && elapsed > waypoint_timeout_sec_) {
        RCLCPP_WARN(
          get_logger(), "航点 %u 导航超时（%.1fs），触发重试", sm_->waypointIndex(), elapsed);
        error_code_ = patrol_interfaces::msg::PatrolStatus::ERR_WAYPOINT_TIMEOUT;
        error_message_ = "航点导航超时";
        cancel_expected_ = true;
        nav_->cancel();
        applyCommand(sm_->handle(PatrolEvent::GOAL_FAILED));
        return;
      }

      switch (nav_->state()) {
        case NavTaskState::SUCCEEDED:
          applyCommand(sm_->handle(PatrolEvent::GOAL_SUCCEEDED));
          wait_start_ = now();
          break;
        case NavTaskState::ABORTED:
        case NavTaskState::REJECTED:
          applyCommand(sm_->handle(PatrolEvent::GOAL_FAILED));
          break;
        case NavTaskState::CANCELED:
          if (!cancel_expected_) {
            RCLCPP_WARN(get_logger(), "导航目标被外部取消，按失败处理");
            applyCommand(sm_->handle(PatrolEvent::GOAL_FAILED));
          }
          break;
        default:
          break;
      }
      return;
    }

    if (state == PatrolState::WAITING) {
      const double waited = (now() - wait_start_).seconds();
      if (waited >= sm_->currentWaitSec()) {
        applyCommand(sm_->handle(PatrolEvent::WAIT_ELAPSED));
        if (sm_->finishedAllLoops()) {
          RCLCPP_INFO(
            get_logger(), "巡逻任务全部完成：共 %u 个航点，%u 轮",
            sm_->completedWaypoints(), sm_->loopCount());
        }
      }
    }
  }

  // ---------------- 副作用执行 ----------------
  void applyCommand(const SmCommand & cmd)
  {
    if (cmd.cancel_goal) {
      cancel_expected_ = true;
      nav_->cancel();
    }

    if (cmd.send_goal) {
      const auto & wps = waypoints_.waypoints;
      if (cmd.target_index >= wps.size()) {
        RCLCPP_ERROR(get_logger(), "目标索引越界: %u (共 %zu)", cmd.target_index, wps.size());
        return;
      }
      const auto & wp = wps[cmd.target_index];

      nav_->detach();
      const bool ok = nav_->sendGoal(wp.x, wp.y, wp.yaw);
      goal_start_ = now();
      cancel_expected_ = false;

      if (!ok) {
        error_code_ = patrol_interfaces::msg::PatrolStatus::ERR_NAV_SERVER_UNAVAILABLE;
        error_message_ = "Nav2 Action Server 不可用";
        applyCommand(sm_->handle(PatrolEvent::GOAL_FAILED));
        return;
      }
      RCLCPP_INFO(
        get_logger(), "前往航点 [%u] x=%.2f y=%.2f yaw=%.2f (wait=%.1fs)",
        cmd.target_index, wp.x, wp.y, wp.yaw, wp.wait_sec);
    }

    publishMarkers();
  }

  // ---------------- 状态发布 ----------------
  void publishStatus()
  {
    patrol_interfaces::msg::PatrolStatus msg;
    msg.header.stamp = now();
    msg.header.frame_id = global_frame_;
    msg.mode = toModeConstant(sm_->state());
    msg.current_waypoint_index = sm_->waypointIndex();
    msg.total_waypoints = static_cast<uint32_t>(waypoints_.waypoints.size());
    msg.completed_waypoints = sm_->completedWaypoints();
    msg.current_loop = sm_->loopCount();
    msg.retry_count = sm_->retryCount();
    msg.distance_remaining = static_cast<float>(nav_->distanceRemaining());
    msg.error_code = (error_code_ != 0) ? error_code_ : sm_->errorCode();
    msg.error_message = !error_message_.empty() ? error_message_ : sm_->errorMessage();
    status_pub_->publish(msg);
  }

  // ---------------- 可视化 ----------------
  void publishMarkers()
  {
    using visualization_msgs::msg::Marker;

    visualization_msgs::msg::MarkerArray arr;
    const auto stamp = now();

    // 先清理，避免航点数量减少时残留旧 Marker
    Marker clear;
    clear.header.frame_id = global_frame_;
    clear.header.stamp = stamp;
    clear.ns = "patrol_waypoints";
    clear.action = Marker::DELETEALL;
    arr.markers.push_back(clear);

    const uint32_t current = sm_->waypointIndex();
    const auto state = sm_->state();
    const bool running = (state == PatrolState::MOVING || state == PatrolState::WAITING ||
      state == PatrolState::PAUSED || state == PatrolState::SAFETY_HOLD);

    for (const auto & wp : waypoints_.waypoints) {
      Marker m;
      m.header.frame_id = global_frame_;
      m.header.stamp = stamp;
      m.ns = "patrol_waypoints";
      m.id = static_cast<int>(wp.index);
      m.type = Marker::SPHERE;
      m.action = Marker::ADD;
      m.pose.position.x = wp.x;
      m.pose.position.y = wp.y;
      m.pose.position.z = 0.15;
      m.pose.orientation.w = 1.0;
      m.scale.x = m.scale.y = m.scale.z = 0.25;
      m.lifetime = rclcpp::Duration(0, 0);  // 永不过期

      if (running && wp.index == current) {
        m.color.r = 1.00f; m.color.g = 0.85f; m.color.b = 0.00f;  // 黄：当前目标
      } else if (wp.index < current) {
        m.color.r = 0.20f; m.color.g = 0.85f; m.color.b = 0.30f;  // 绿：已完成
      } else {
        m.color.r = 0.60f; m.color.g = 0.60f; m.color.b = 0.60f;  // 灰：未访问
      }
      m.color.a = 0.9f;
      arr.markers.push_back(m);

      Marker label = m;
      label.ns = "patrol_labels";     // 必须换 ns，否则 ID 与球体冲突
      label.type = Marker::TEXT_VIEW_FACING;
      label.scale.z = 0.22;
      label.pose.position.z = 0.45;
      label.color.r = label.color.g = label.color.b = 1.0f;
      label.color.a = 0.95f;
      label.text = "WP" + std::to_string(wp.index);
      arr.markers.push_back(label);
    }

    marker_pub_->publish(arr);
  }

  // ---------------- 工具 ----------------
  static uint8_t toModeConstant(PatrolState s)
  {
    return static_cast<uint8_t>(s);  // 与 msg 的 MODE_* 常量一一对应
  }

  // ---------------- 参数缓存 ----------------
  std::vector<double> waypoint_x_, waypoint_y_, waypoint_yaw_, waypoint_wait_;
  int loop_count_{0};
  int max_retries_{2};
  bool skip_failed_waypoint_{true};
  double waypoint_timeout_sec_{60.0};
  bool auto_start_{false};
  std::string global_frame_{"map"};
  std::string action_name_{"navigate_to_pose"};
  std::string status_topic_{"/patrol/status"};
  std::string markers_topic_{"/patrol/markers"};
  std::string mode_service_{"/patrol/set_mode"};
  std::string safety_topic_{"/safety/emergency_stop"};
  int tick_period_ms_{100};
  double status_publish_hz_{1.0};
  bool use_safety_hold_{true};

  // ---------------- 运行时状态 ----------------
  WaypointSet waypoints_;
  bool waypoints_valid_{false};
  std::unique_ptr<PatrolStateMachine> sm_;
  std::unique_ptr<NavClient> nav_;

  rclcpp::Publisher<patrol_interfaces::msg::PatrolStatus>::SharedPtr status_pub_;
  rclcpp::Publisher<visualization_msgs::msg::MarkerArray>::SharedPtr marker_pub_;
  rclcpp::Subscription<std_msgs::msg::Bool>::SharedPtr safety_sub_;
  rclcpp::Service<patrol_interfaces::srv::SetPatrolMode>::SharedPtr mode_srv_;
  rclcpp::TimerBase::SharedPtr tick_timer_;
  rclcpp::TimerBase::SharedPtr status_timer_;

  bool emergency_{false};
  bool cancel_expected_{false};
  rclcpp::Time wait_start_{0, 0, RCL_ROS_TIME};
  rclcpp::Time goal_start_{0, 0, RCL_ROS_TIME};
  uint16_t error_code_{0};
  std::string error_message_;
};

}  // namespace patrol_robot_core

// ---------------- 入口：使用多线程执行器 ----------------
// 理由：服务回调、Action 回调与定时器需要并发执行；单线程执行器下
//       任一回调阻塞会拖垮整个节点（见 02 文档 ADR-05）。
int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<patrol_robot_core::PatrolNode>();

  rclcpp::executors::MultiThreadedExecutor executor(rclcpp::ExecutorOptions(), 2);
  executor.add_node(node);
  executor.spin();

  rclcpp::shutdown();
  return 0;
}
```

> 若需持续刷新 Marker，可另建 2 Hz 定时器调用同一方法。

## 7. `safety_guard_node` 详细设计

### 7.1 检测几何

```
                     机器人俯视图（base_link 帧）
                                +x（前进方向）
                                 ▲
                    ╱────────────┼────────────╲
                 ╱               │               ╲
              ╱   前向检测扇区     │                ╲
           ╱      FOV = 60°      │                 ╲
        ╱                         │                  ╲
   ────●──────────────────────────┼───────────────────●───► +y
        ╲          half_fov = 30° │                 ╱
           ╲                     │               ╱
              ╲                  │            ╱
                 ╲               │         ╱
                    ╲────────────┼──────╱
                                 │
   取扇区内所有有效激光点的最小距离 min_distance

   迟滞判定：
     min_distance < stop_distance    → emergency = true
     min_distance > resume_distance  → emergency = false
     （两者之间保持原状态，抑制抖动）
```

### 7.2 迟滞的必要性

若只用单一阈值，传感器噪声会让机器人在阈值附近反复翻转 `emergency`，
巡逻节点随之反复 cancel / send_goal，机器人出现"点头"式抖动。
引入 `resume_distance > stop_distance`（默认 0.60 > 0.30）的迟滞区间后，
状态翻转被有效抑制（FR-10.2）。

### 7.3 为什么不接管 `/cmd_vel`

默认**不**发布 `/cmd_vel`（ADR-06）：

1. Nav2 的 `controller_server` 是 `/cmd_vel` 的唯一权威发布者，多发布者会导致速度指令竞争；
2. Nav2 自身具备恢复行为，盲目接管会破坏其行为树状态；
3. 分层职责：安全节点只负责"感知与判断"，任务层负责"决策与执行"。

参数 `allow_cmd_vel_override`（默认 `false`）保留应急接管能力，开启时紧急状态下发布零速 `Twist`。

```cpp
// 文件用途：激光安全判定（纯逻辑，可独立单元测试）
#ifndef PATROL_ROBOT_CORE__SAFETY_EVALUATOR_HPP_
#define PATROL_ROBOT_CORE__SAFETY_EVALUATOR_HPP_

#include <limits>
#include <string>

#include "sensor_msgs/msg/laser_scan.hpp"

namespace patrol_robot_core
{

/// @brief 一次安全评估的结果
struct SafetyResult
{
  double min_distance{std::numeric_limits<double>::infinity()};  ///< 扇区内最小距离
  bool emergency{false};        ///< 评估后的紧急标志
  bool state_changed{false};    ///< 与上次相比是否翻转
  bool has_valid_point{false};  ///< 扇区内是否存在有效点
};

/// @brief 前向扇区障碍检测 + 迟滞判定
class SafetyEvaluator
{
public:
  struct Config
  {
    double stop_distance{0.30};    ///< 触发紧急停车的距离阈值（m）
    double resume_distance{0.60};  ///< 解除紧急状态的距离阈值（m），必须 > stop_distance
    double fov_deg{60.0};          ///< 前向扇区总视场角（度）
    double range_min{0.02};        ///< 有效距离下限（m）
    double range_max{3.50};        ///< 有效距离上限（m）
  };

  explicit SafetyEvaluator(const Config & config);

  /// @brief 校验配置合法性
  static bool validateConfig(const Config & config, std::string & error);

  /// @brief 处理一帧激光数据
  SafetyResult update(const sensor_msgs::msg::LaserScan & scan);

  bool emergency() const { return emergency_; }
  void reset() { emergency_ = false; }
  const Config & config() const { return config_; }

private:
  Config config_;
  bool emergency_{false};
};

}  // namespace patrol_robot_core

#endif  // PATROL_ROBOT_CORE__SAFETY_EVALUATOR_HPP_
```

`src/safety_evaluator.cpp`

```cpp
// 文件用途：SafetyEvaluator 实现
#include "patrol_robot_core/safety_evaluator.hpp"

#include <algorithm>
#include <cmath>
#include <sstream>
#include <stdexcept>

namespace patrol_robot_core
{
namespace
{
constexpr double kDeg2Rad = 0.017453292519943295;
}  // namespace

SafetyEvaluator::SafetyEvaluator(const Config & config)
: config_(config)
{
  std::string error;
  if (!validateConfig(config_, error)) {
    throw std::invalid_argument("SafetyEvaluator 配置非法: " + error);
  }
}

bool SafetyEvaluator::validateConfig(const Config & config, std::string & error)
{
  error.clear();
  if (config.stop_distance <= 0.0) {
    error = "stop_distance 必须大于 0";
    return false;
  }
  if (config.resume_distance <= config.stop_distance) {
    std::ostringstream oss;
    oss << "resume_distance(" << config.resume_distance << ") 必须大于 stop_distance("
        << config.stop_distance << ")，否则会产生抖动";
    error = oss.str();
    return false;
  }
  if (config.fov_deg <= 0.0 || config.fov_deg > 360.0) {
    error = "fov_deg 必须在 (0, 360] 范围内";
    return false;
  }
  if (config.range_max <= config.range_min) {
    error = "range_max 必须大于 range_min";
    return false;
  }
  return true;
}

SafetyResult SafetyEvaluator::update(const sensor_msgs::msg::LaserScan & scan)
{
  SafetyResult result;

  // FR-10.1：空数据不改变状态
  if (scan.ranges.empty() || scan.angle_increment == 0.0f) {
    result.emergency = emergency_;
    return result;
  }

  const double half_fov = config_.fov_deg * 0.5 * kDeg2Rad;
  const double eff_min = std::max(config_.range_min, static_cast<double>(scan.range_min));
  const double eff_max = std::min(config_.range_max, static_cast<double>(scan.range_max));

  double min_dist = std::numeric_limits<double>::infinity();
  bool found = false;

  for (size_t i = 0; i < scan.ranges.size(); ++i) {
    const double angle = scan.angle_min + static_cast<double>(i) * scan.angle_increment;
    if (std::fabs(angle) > half_fov) {
      continue;
    }
    const double r = scan.ranges[i];
    // 过滤 NaN / Inf / 超量程
    if (!std::isfinite(r) || r < eff_min || r > eff_max) {
      continue;
    }
    if (r < min_dist) {
      min_dist = r;
      found = true;
    }
  }

  result.has_valid_point = found;
  result.min_distance = found ? min_dist : std::numeric_limits<double>::infinity();

  const bool prev = emergency_;
  if (found && min_dist < config_.stop_distance) {
    emergency_ = true;
  } else if (!found || min_dist > config_.resume_distance) {
    emergency_ = false;
  }
  // 其余情况保持原状态（迟滞区间）

  result.emergency = emergency_;
  result.state_changed = (prev != emergency_);
  return result;
}

}  // namespace patrol_robot_core
```

`src/safety_guard_node.cpp`

```cpp
// 文件用途：激光安全守护节点
//   订阅 /scan → 前向扇区最小距离 → 迟滞判定 → 发布安全标志
//   注意：默认不发布 /cmd_vel（见 02 文档 ADR-06）
#include <memory>
#include <stdexcept>
#include <string>

#include "geometry_msgs/msg/twist.hpp"
#include "patrol_robot_core/safety_evaluator.hpp"
#include "rclcpp/rclcpp.hpp"
#include "sensor_msgs/msg/laser_scan.hpp"
#include "std_msgs/msg/bool.hpp"
#include "std_msgs/msg/float32.hpp"

namespace patrol_robot_core
{

class SafetyGuardNode : public rclcpp::Node
{
public:
  SafetyGuardNode()
  : rclcpp::Node("safety_guard_node")
  {
    SafetyEvaluator::Config cfg;
    cfg.stop_distance = declare_parameter<double>("stop_distance", 0.30);
    cfg.resume_distance = declare_parameter<double>("resume_distance", 0.60);
    cfg.fov_deg = declare_parameter<double>("fov_deg", 60.0);
    cfg.range_min = declare_parameter<double>("range_min", 0.02);
    cfg.range_max = declare_parameter<double>("range_max", 3.50);

    std::string error;
    if (!SafetyEvaluator::validateConfig(cfg, error)) {
      RCLCPP_FATAL(get_logger(), "安全参数非法：%s", error.c_str());
      throw std::invalid_argument(error);   // 拒绝启动，符合 NFR-09
    }
    evaluator_ = std::make_unique<SafetyEvaluator>(cfg);

    const std::string scan_topic = declare_parameter<std::string>("scan_topic", "scan");
    const std::string emergency_topic =
      declare_parameter<std::string>("emergency_topic", "/safety/emergency_stop");
    const std::string distance_topic =
      declare_parameter<std::string>("distance_topic", "/safety/nearest_obstacle_distance");
    allow_cmd_vel_override_ = declare_parameter<bool>("allow_cmd_vel_override", false);

    rclcpp::QoS emergency_qos(1);
    emergency_qos.transient_local();  // 晚启动的订阅者也能拿到当前状态

    emergency_pub_ = create_publisher<std_msgs::msg::Bool>(emergency_topic, emergency_qos);
    distance_pub_ = create_publisher<std_msgs::msg::Float32>(distance_topic, 10);

    // SensorDataQoS（best_effort）：与 reliable 发布者兼容，且适合高频传感器数据
    scan_sub_ = create_subscription<sensor_msgs::msg::LaserScan>(
      scan_topic, rclcpp::SensorDataQoS(),
      std::bind(&SafetyGuardNode::onScan, this, std::placeholders::_1));

    if (allow_cmd_vel_override_) {
      cmd_vel_pub_ = create_publisher<geometry_msgs::msg::Twist>("cmd_vel", 10);
      RCLCPP_WARN(
        get_logger(),
        "allow_cmd_vel_override=true：安全节点将直接发布 /cmd_vel，"
        "请确认不与 Nav2 控制器冲突！");
    }

    RCLCPP_INFO(
      get_logger(), "safety_guard_node 就绪: stop=%.2fm resume=%.2fm fov=%.0f deg scan=%s",
      cfg.stop_distance, cfg.resume_distance, cfg.fov_deg, scan_topic.c_str());
  }

private:
  void onScan(const sensor_msgs::msg::LaserScan::SharedPtr scan)
  {
    const auto result = evaluator_->update(*scan);

    std_msgs::msg::Float32 dist_msg;
    dist_msg.data = static_cast<float>(result.min_distance);
    distance_pub_->publish(dist_msg);

    if (!result.state_changed) {
      return;
    }

    std_msgs::msg::Bool flag;
    flag.data = result.emergency;
    emergency_pub_->publish(flag);

    if (result.emergency) {
      RCLCPP_WARN(
        get_logger(), "前方障碍过近（%.2f m < %.2f m），置位紧急标志",
        result.min_distance, evaluator_->config().stop_distance);
    } else {
      RCLCPP_INFO(
        get_logger(), "前方畅通（%.2f m > %.2f m），解除紧急标志",
        result.min_distance, evaluator_->config().resume_distance);
    }

    if (allow_cmd_vel_override_ && cmd_vel_pub_ && result.emergency) {
      cmd_vel_pub_->publish(geometry_msgs::msg::Twist());  // 全零 → 停车
    }
  }

  std::unique_ptr<SafetyEvaluator> evaluator_;
  rclcpp::Publisher<std_msgs::msg::Bool>::SharedPtr emergency_pub_;
  rclcpp::Publisher<std_msgs::msg::Float32>::SharedPtr distance_pub_;
  rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr cmd_vel_pub_;
  rclcpp::Subscription<sensor_msgs::msg::LaserScan>::SharedPtr scan_sub_;
  bool allow_cmd_vel_override_{false};
};

}  // namespace patrol_robot_core

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  try {
    rclcpp::spin(std::make_shared<patrol_robot_core::SafetyGuardNode>());
  } catch (const std::exception & e) {
    RCLCPP_FATAL(rclcpp::get_logger("safety_guard_node"), "启动失败: %s", e.what());
    rclcpp::shutdown();
    return 1;
  }
  rclcpp::shutdown();
  return 0;
}
```

### 7.5 参数调优建议

| 参数 | 默认 | 调优建议 |
| --- | --- | --- |
| `stop_distance` | 0.30 | TurtleBot3 Burger 外接圆半径约 0.105 m，取 0.25–0.35 合理；需大于 Nav2 代价地图 `inflation_radius` 才有意义 |
| `resume_distance` | 0.60 | 一般取 `stop_distance × 2`；太小会抖动，太大会让机器人"犹豫" |
| `fov_deg` | 60 | 窄走廊可加到 90；只关心正前方用 30 |
| `range_max` | 3.50 | 与 LiDAR 有效量程一致，避免远处噪声误判 |

## 8. 可视化设计（MarkerArray）

| 命名空间 | 类型 | ID | 含义 | 颜色 |
| --- | --- | --- | --- | --- |
| `patrol_waypoints` | `SPHERE` | 航点索引 | 航点位置 | 灰 `(0.6,0.6,0.6)` = 未访问<br>黄 `(1.0,0.85,0)` = 当前目标<br>绿 `(0.2,0.85,0.3)` = 已完成 |
| `patrol_labels` | `TEXT_VIEW_FACING` | 航点索引 | `WP0` / `WP1` … | 白 |
| （首元素） | `DELETEALL` | — | 清理上一帧 | — |

**关键设计点**：

1. 每帧先发 `DELETEALL`，避免航点数量减少时残留旧 Marker。
2. `lifetime = rclcpp::Duration(0, 0)`（0 = 永不过期），配合 `transient_local` QoS，RViz 晚启动也能看到。
3. `ns` 必须区分，否则 `patrol_waypoints` 与 `patrol_labels` 的同 ID Marker 会互相覆盖。
4. Marker 的 `frame_id` 必须是 `map`，且与 RViz 的 Fixed Frame 一致，否则不显示。
5. `orientation.w = 1.0` 必须显式设置，否则四元数未初始化会导致 Marker 姿态异常。

```python
            }.items(),
```

```python
                    PythonLaunchDescriptionSource(
                        os.path.join(pkg_bringup, 'launch', 'patrol_nodes.launch.py')),
                    launch_arguments={

                ),
            ],
        ),
    ])
```

> **为什么需要 `TimerAction` 延迟 8 秒**：Nav2 的 `lifecycle_manager` 需要按依赖顺序
> 逐个 configure/activate（map_server → amcl → planner → controller → bt_navigator），
> 完整激活通常需要 5–10 秒。若任务层过早发送目标，Action Server 尚未激活，目标会被静默丢弃。
> 双保险：`NavClient::waitForServer(10s)` 也会阻塞等待。

## 12. 关键实现要点与已知陷阱

| 编号 | 要点 / 陷阱 | 正确做法 |
| --- | --- | --- |
| K-01 | **不要在回调里 `.get()` 等 Action 结果** | 非阻塞 `async_send_goal` + 回调更新状态（§4.2） |
| K-02 | 单线程执行器下服务回调可能阻塞 tick | 使用 `MultiThreadedExecutor(threads=2)`（§6.5 入口） |
| K-03 | 状态机被多线程并发访问 | 所有状态迁移只在 `tick()` 中执行，回调只置标志（§6.2 单点更新模型） |
| K-04 | `use_sim_time` 不一致导致 TF 时间戳错乱 | 所有节点统一 `use_sim_time:=true` |
| K-05 | `/scan` QoS 不匹配导致收不到数据 | 订阅端用 `rclcpp::SensorDataQoS()`（best_effort 兼容 reliable 发布者） |
| K-06 | 安全标志的晚启动订阅者收不到 | 发布/订阅均使用 `transient_local` |
| K-07 | Marker `ns` 相同导致 ID 冲突 | 不同用途用不同 `ns`（§8） |
| K-08 | Marker `frame_id` 与 RViz Fixed Frame 不一致 | 统一 `map` |
| K-09 | 目标在 Nav2 激活前发送被静默丢弃 | `wait_for_action_server(10s)` + launch 中 `TimerAction(8s)` 双保险 |
| K-10 | 航点落在障碍物内导致无限重试 | `waypoint_timeout_sec` + `max_retries` + `skip_failed_waypoint` 三重保护 |
| K-11 | Marker 的 `orientation` 未初始化 | 显式设 `orientation.w = 1.0` |
| K-12 | 两个节点都发 `/cmd_vel` 造成控制权竞争 | 默认禁止安全节点接管（ADR-06） |
| K-13 | 参数数组长度不一致导致越界 | `WaypointLoader::fromArrays` 强制校验（VL-01） |
| K-14 | `get_parameter` 未先 `declare_parameter` 会抛异常 | 所有参数先声明并给默认值 |
| K-15 | `cancel()` 时目标尚未被接受，`goal_handle_` 为空 | 回退到 `async_cancel_all_goals()`（§4.5） |
| K-16 | 重试时未清理旧结果，读到上一轮的 SUCCEEDED | `sendGoal` 前先 `detach()` |
| K-17 | `-Wall -Wextra` 报未使用参数警告 | 省略参数名或用 `[[maybe_unused]]` |
| K-18 | 时间比较用 `rclcpp::Time` 而非 `chrono` | 需兼容 `use_sim_time`，必须用 `this->now()` |

## 14. v0.2.0 实现偏差记录

> 按 14 文档 CD-05「先改文档再改代码」原则，本节记录代码实现相对 v0.1 设计清单的偏差与理由。
> 偏差均为架构规范（16 文档）驱动的修正，不是实现简化；仓库代码为准。

| # | 位置（本文档） | v0.1 设计 | v0.2.0 实现 | 理由 |
| --- | --- | --- | --- | --- |
| 1 | §7.4 `SafetyEvaluator` | `update(const sensor_msgs::msg::LaserScan &)` | `update(const LaserScanView &)`（纯数据结构，节点内完成消息→视图转换） | AS-65：纯逻辑类不得 include 任何 ROS 头文件 |
| 2 | §6.2 服务并发 | `onSetMode` 直接驱动状态机 | 服务只入队事件，由 tick 串行处理；服务侧有界等待（≤1 s） | AS-54 / K-03 单点更新模型；等待属已登记豁免 `AS-EXEMPT(AS-53)` |
| 3 | §6.5 启动行为 | Nav2 不可用时 `ERROR` 后继续运行 | `FATAL` + 非零退出；`ERR_NAV_SERVER_UNAVAILABLE` 保留给运行期 | AS-62：禁止"进程活着但功能不可用"的静默失败 |
| 4 | §9.3 `navigation.launch.py` | 复用 `turtlebot3_navigation2` 的 launch | 直接组合 `nav2_bringup/bringup_launch.py` + 本项目 `patrol.rviz` | 需要含 MarkerArray 的本项目 RViz 配置；仍复用官方 launch（AS-64） |
| 5 | §3.5 `normalizeAngle` | `fmod(yaw+π, 2π)-π`（π 映射为 -π） | 结果域 `(-π, π]`，π 保持为 π | 对齐 06 §7.2 与 08 文档 TC-U-03c |
| 6 | §6.5 错误管理 | `RESET` 只清状态机统计 | `RESET` 同时清节点级错误码与错误信息 | FR-07「RESET 清零统计与错误」 |
| 7 | §7.4 距离话题 | 空数据时发布 `inf` | 空数据发布 `0.0`（未收到有效数据），无扇区障碍发布 `inf` | 对齐 05 §2.4 的特殊值契约 |
| 8 | §10.1 默认航点 | 4 个航点（面向 5×5 世界） | 3 个航点，适配 `tb3_world` 六边形世界并留足安全余量 | 原示例点落在圆柱阵列/墙体附近，默认可达性无法保证 |
| 9 | §7.4 参数 | 无 | 新增 `cmd_vel_topic`（默认 `"cmd_vel"`） | AS-79 拓扑标识参数化；已同步 05 §5.2 |
